# Developer Toolkit

A small open-source collection of browser-based utilities for developers.

## Current tools

- JSON formatter and validator
- Base64 encoder and decoder
- UUID generator
- URL encoder and decoder

## Run locally

No build system is required.

1. Clone or download the repository.
2. Open `index.html` in a browser.

## Contributing

Contributions are welcome. You can add utilities, improve accessibility, fix bugs, or improve the documentation.

Please open an issue before making a large change so the proposed direction can be discussed.
